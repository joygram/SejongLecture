# 우리 팀 리포트 완성하기

- 자료 = 인사혁신처 2026년 7급 공채 1차 필기시험 응시현황.
- 사용할 칸 = 분야·시험을 본 사람 수, 원자료의 직군 계 응시 인원.
- 흐름 = 슬라이드 순서. 메모 → 서론 → 표·세 문장·그림 → 퇴고·완성본 → 팀 채팅.
- 붙이는 법 = 카드 1부터 같은 채팅에 순서대로.
- 카드 원문·복사 = [프롬프트 카드](prompts.html), 한 번에 만들기 = [고급 정리](advanced.html).

## 카드 1 · 메모를 붙여 초안을 받아요

```text
올해 7급 시험에는 어떤 분야에 사람이 많이 왔을까?
팀원은 사람이 많으면 인기 있는 분야인지 궁금해한다.
자료를 보기 전부터 “인기가 높다”는 결론을 내리고 싶지는 않다.

위 메모로 리포트 서론 5문장만 써줘. 숫자는 쓰지 말고, 끝에 나에게 물을 질문 1개만 붙여. 다른 설명은 빼.
```

- 생각할 것 = 무엇을 쓰려는지는 우리가 정하고, AI에는 정리와 질문을 부탁해요.
- 확인할 것 = 원래 메모와 비교해 살릴 문장·우리 생각과 다른 문장 각 하나 선택.

## 카드 2 · 아까 본 표를 붙여요

```text
분야,시험을 본 사람
행정직,11447
과학기술직,2871
외무영사직,1216
(2026년 7급 공채 1차 필기 응시인원, 인사혁신처)

이 표에서 알 수 있는 사실 세 문장만 써줘. 숫자를 그대로 넣고 ‘인기’ 같은 평가는 빼.
그리고 같은 수치로 가로 막대그래프 두 개를 한 장에 나란히 그려줘. A는 행정직만, B는 외무영사직만 강조하고 축·순서는 같게. 코드나 설명은 빼.
```

- 생각할 것 = 숫자와 말이 같은지 확인. 같은 숫자도 강조에 따라 먼저 보이는 것이 달라져요.
- 확인할 것 = 행정직 11,447 / 과학기술직 2,871 / 외무영사직 1,216 대조. 두 그림 축·순서 동일.

## 카드 3 · “전문적으로”보다 “우리 뜻대로”

```text
지금까지 쓴 서론·세 문장·그림을 초안으로 보고, 내 메모에 없던 주장이나 상투적인 표현만 짚어줘. 그 문장만 고치고 나머지는 그대로 둬.
그다음 제목 → 서론 → 표 → 그림 A → 세 문장 → 이 자료로 알 수 없는 것 → 출처 순서로 완성본을 정리해줘. 새 사실은 넣지 마.
```

- 생각할 것 = 똑같은 사실도 누구에게 무슨 이야기를 할지에 따라 첫 문장이 달라져요.
- 확인할 것 = 완성본 숫자와 표 대조. 그림 B로 바꿀지 결정.

## 완성 뒤 · 팀 채팅방에 공유

```text
이 완성본으로 팀 채팅방에 보낼 메시지를 써줘. 결론(숫자 그대로) 한 줄, 아직 모르는 것 한 줄, 팀원이 할 일 2개(무엇을·어디서). 인사말·설명은 빼고, 실제로 보내지는 마.
```

- 생각할 것 = 요약이 아니라 팀원이 다음에 할 일이 보이는 메시지예요.
- 확인할 것 = 결론·모르는 것이 리포트와 일치, 할 일마다 대상이 있음. 실제 전송 없음.
