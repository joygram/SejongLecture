# 내 보고서 환경 · 도구별 활용 가이드

- 확인 기준 = 2026-11-04 공식 문서, 개인·학교 계정의 실제 화면은 미검증.
- Google Workspace = Docs 등 Google 환경, ChatGPT Projects = 과제별 맥락을 모으는 기능.
- 공통 흐름 = 스타일 지침 → 원자료 → 요청 → 결과 검토 → 원본 보관.
- 계정 메뉴가 다르면 일반 채팅에 공통 지침·표·요청을 함께 붙여넣어 같은 과제 수행.

## 공통 스타일 지침

```text
우리가 누구에게 무슨 이야기를 쓰려는지, 원래 메모부터 확인해. 글을 정리할 때는 없는 경험·출처·숫자를 넣지 말고 물어봐. 표와 그림과 문장이 같은 자료를 말하는지 확인해. 퇴고는 내 뜻이 달라지는 곳을 짚고 2안을 제시한 뒤 내 선택을 기다려. 보고서와 팀 채팅 메시지는 각각 읽는 사람이 다음에 알아야 할 것에 맞춰 써줘.
```

## Gemini · Gems가 보이는 계정

- 용도 = 반복할 글쓰기 지침과 참고자료를 Gem에 저장.
- Gemini 웹 사이드바에서 Gems → 새 Gem 선택.
- 이름을 내 리포트 편집자로 정하고 아래 공통 지침 입력.
- 필요한 공개 자료를 지식 파일로 추가, 미리보기에서 짧은 입력으로 시험.
- 저장한 Gem을 열어 이번 과제 자료와 아래 요청 입력.

### 시험 입력

```text
자료: 인사혁신처, 2026년 국가공무원 7급 공채 1차 필기시험 응시현황, 직군 계 응시 인원.
분야,시험을 본 사람
행정직,11447
과학기술직,2871
외무영사직,1216

이 자료를 처음 보는 팀원에게 설명할 리포트를 쓸 거야. 먼저 우리 팀이 무슨 이야기를 하려는지 물어봐. 내가 답하면 그 생각을 살릴 첫 문장 두 안을 제안하고 멈춰. 표에 없는 이유나 인기는 추가하지 마.
```

- 대체 = Gems가 안 보이면 Skills 경로 확인. 둘 다 없으면 공통 지침+자료+요청을 일반 새 채팅에 함께 입력.
- 확인 사항 = 2026-11-04 공식 문서 확인. 개인 계정은 2026년 11월부터 Skills로 전환, 직장·학교는 별도 일정. 이번 사용자 계정의 실제 메뉴는 미검증.
- 공식 안내 = [Google · Gems 사용](https://support.google.com/gemini/answer/15146780?hl=ko), [Google · Gems 전환 안내](https://support.google.com/gemini/answer/18560919?hl=ko)

## Gemini · Skills가 보이는 계정

- 용도 = 재사용할 요청 사항을 스킬로 만들고 채팅에 적용.
- Gemini의 맞춤설정 → 스킬에서 만들기 선택.
- 수동으로 만들기에서 이름·설명·아래 공통 지침 입력.
- 만든 스킬을 채팅에서 선택해 적용하고 이번 자료와 요청 입력.
- 짧은 테스트로 문체·출처 처리가 지침과 같은지 확인 후 필요 시 스킬 수정.

### 시험 입력

```text
자료: 인사혁신처, 2026년 국가공무원 7급 공채 1차 필기시험 응시현황, 직군 계 응시 인원.
분야,시험을 본 사람
행정직,11447
과학기술직,2871
외무영사직,1216

이 자료를 처음 보는 팀원에게 설명할 리포트를 쓸 거야. 먼저 우리 팀이 무슨 이야기를 하려는지 물어봐. 내가 답하면 그 생각을 살릴 첫 문장 두 안을 제안하고 멈춰. 표에 없는 이유나 인기는 추가하지 마.
```

- 대체 = 스킬 생성·파일 메뉴가 없으면 일반 채팅에 지침과 자료를 함께 붙여넣기. 계정별 지원 상태는 공식 도움말에서 확인.
- 확인 사항 = 지침 재사용과 파일 보관은 구분. Gem의 지식 파일이 새 환경에서도 쓰이는지 확인. 현재 Skills와 Canvas·Deep Research의 호환을 전제로 시연하지 않음.
- 공식 안내 = [Google · 스킬 생성·관리](https://support.google.com/gemini/answer/17094296?hl=ko), [Google · 전환과 호환 제한](https://support.google.com/gemini/answer/18560919?hl=ko)

## ChatGPT · Projects

- 용도 = 한 과제의 채팅·파일·지침을 같은 프로젝트에 모으기.
- ChatGPT에서 프로젝트를 만들거나 열고 이름을 우리 팀 리포트로 지정.
- 프로젝트 지침에 아래 공통 지침을 저장.
- 프로젝트 자료 영역에 공개 원자료와 내 스타일 예시를 추가.
- 프로젝트 안에서 초안·검증·퇴고 채팅을 구분하고 아래 요청으로 시작.

### 시험 입력

```text
자료: 인사혁신처, 2026년 국가공무원 7급 공채 1차 필기시험 응시현황, 직군 계 응시 인원.
분야,시험을 본 사람
행정직,11447
과학기술직,2871
외무영사직,1216

이 자료를 처음 보는 팀원에게 설명할 리포트를 쓸 거야. 먼저 우리 팀이 무슨 이야기를 하려는지 물어봐. 내가 답하면 그 생각을 살릴 첫 문장 두 안을 제안하고 멈춰. 표에 없는 이유나 인기는 추가하지 마.
```

- 대체 = 프로젝트 지침 메뉴를 못 찾으면 지침 파일을 자료로 추가하고 채팅에서 그 파일 적용을 명시. 프로젝트를 사용할 수 없으면 일반 새 채팅에 지침·자료 함께 입력.
- 확인 사항 = 공식 OpenAI 문서 기준 2026-11-04. ChatGPT 프로젝트는 관련 맥락을 모으는 기능이며 내 PC 폴더에 자동 접근하는 기능으로 설명하지 않음. 파일과 최종 문서는 직접 열어 대조.
- 공식 안내 = [OpenAI Docs · Projects and chats](https://learn.chatgpt.com/docs/projects)

## Google Workspace · Docs의 Gemini

- 용도 = 편집 가능한 문서 원본에서 요청하고 변경 제안을 검토.
- Google Docs에서 리포트 원본을 열고 Gemini 기능 선택.
- 사용 가능한 소스 추가 또는 @ 참조로 원자료 지정.
- 아래 수정 요청을 입력하고 특정 절이나 문장을 명시.
- 제안된 변경을 검토해 필요한 것만 수락하고 수치·출처 재대조.

### 시험 입력

```text
결과 절의 문체만 담백한 문어체로 다듬어 줘. 수치·출처·계산 기준·내 결론은 바꾸지 마. 새 사실을 추가하지 말고, 수정할 부분을 제안으로 보여 줘.
```

- 대체 = 학교 계정에 Gemini가 안 보이면 사본의 필요한 문단만 일반 채팅에서 검토하고, 확인한 수정만 Docs 원본에 직접 반영.
- 확인 사항 = Gemini in Docs는 지원 구독·학교 설정에 따라 제공 여부가 달라짐. 별도의 글쓰기 스타일 참조 메뉴는 공식 문서상 Workspace Experiments 기능이므로 전원 사용을 전제로 하지 않음. Google Workspace와 ChatGPT Projects는 같은 기능명이 아님.
- 공식 안내 = [Google Docs · Gemini 작성·수정](https://support.google.com/docs/answer/13447609?hl=ko)
