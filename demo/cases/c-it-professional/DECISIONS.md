# 사람의 판정 — 국가기술자격 기술사 · 정보기술분야

- 결정 칸에 선택지 하나를 그대로 적고, 근거를 한 줄로 적는다
- 아래는 강사 예시. 학생은 자기 판단으로 바꿔 적고 다시 build

## 분모
- 선택지 = 응시 / 접수
- 결정 = 응시
- 근거 = 결시자는 시험을 치르지 않았음

## 집계 단위
- 선택지 = 종목 행만 / 분야 행만
- 결정 = 종목 행만
- 근거 = 분야 행은 두 종목의 합

## 포함 종목
- 선택지 = 전부 / 일부
- 결정 = 전부
- 근거 = 두 종목뿐

## 작은 표본
- 선택지 = 포함·인원 표시 / 제외 / 비율 쓰지 않음
- 결정 = 비율 쓰지 않음
- 근거 = 실기 응시 67명·12명. 한두 명으로 비율이 크게 흔들려 인원만 보임

## 성별
- 선택지 = 본문 / 부록 / 쓰지 않음
- 결정 = 쓰지 않음
- 근거 = 인원이 너무 적어 성별로 나누면 개인이 드러날 수 있음

## 가장 어려운 시험
- 선택지 = 필기 기준으로 씀 / 실기 기준으로 씀 / 쓰지 않음
- 결정 = 쓰지 않음
- 근거 = 표본이 작아 비교 자체를 하지 않음
