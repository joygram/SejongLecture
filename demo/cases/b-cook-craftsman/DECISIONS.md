# 사람의 판정 — 국가기술자격 기능사 · 조리분야

- 결정 칸에 선택지 하나를 그대로 적고, 근거를 한 줄로 적는다
- 아래는 강사 예시. 학생은 자기 판단으로 바꿔 적고 다시 build

## 분모
- 선택지 = 응시 / 접수
- 결정 = 응시
- 근거 = 결시자는 시험을 치르지 않았음

## 집계 단위
- 선택지 = 종목 행만 / 분야 행만
- 결정 = 종목 행만
- 근거 = 한식·양식·일식·중식을 나란히 보려는 글

## 포함 종목
- 선택지 = 전부 / 일부
- 결정 = 전부
- 근거 = 조주(바텐더)도 공식 분류상 조리분야. 묶음 성격이 다르다는 점은 한계에 적음

## 작은 표본
- 선택지 = 포함·인원 표시 / 제외 / 비율 쓰지 않음
- 결정 = 포함·인원 표시
- 근거 = 복어조리 등 응시가 적은 종목도 인원과 함께 보임

## 성별
- 선택지 = 본문 / 부록 / 쓰지 않음
- 결정 = 쓰지 않음
- 근거 = 이 글의 질문은 종목 간 차이. 원인 정보 없는 성별 비교는 넣지 않음

## 가장 어려운 시험
- 선택지 = 필기 기준으로 씀 / 실기 기준으로 씀 / 쓰지 않음
- 결정 = 실기 기준으로 씀
- 근거 = 조리 기능사는 실기가 자격의 핵심. 기준을 문장에 밝힘
