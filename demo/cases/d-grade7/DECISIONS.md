# 사람의 판정 — 국가공무원 7급 공채 1차 필기 응시현황 (2026)

- 결정 칸에 선택지 하나를 그대로 적고, 근거를 한 줄로 적는다
- 아래는 강사 예시. 학생은 자기 판단으로 바꿔 적고 다시 build

## 경쟁률 분모
- 선택지 = 응시인원 / 응시대상인원
- 결정 = 응시인원
- 근거 = 결시율 38.9%. 시험장에 오지 않은 사람은 실제 경쟁에 참여하지 않음

## 집계 단위
- 선택지 = 모집단위 / 직군 계 / 총계만
- 결정 = 모집단위
- 근거 = 직군 계는 모집단위의 합. 표와 그림에서 한 층만 씀

## '-' 칸
- 선택지 = 0으로 읽음 / 미공개로 두고 계산 제외
- 결정 = 미공개로 두고 계산 제외
- 근거 = 원문에 '-' 설명이 없음. 확인 안 된 0을 만들지 않음

## 구분모집
- 선택지 = 일반·장애인 나눠서 / 합쳐서 / 일반만
- 결정 = 일반·장애인 나눠서
- 근거 = 구분모집은 별도 경쟁을 두려는 제도. 합치면 그 구분이 사라짐

## 선발 1–2명 단위
- 선택지 = 경쟁률 표시 / 표시하되 순위에서 제외 / 쓰지 않음
- 결정 = 표시하되 순위에서 제외
- 근거 = 한 명 차이로 경쟁률이 수십씩 바뀜. 값은 보이되 비교 순위에는 넣지 않음

## '경쟁이 가장 센 직렬'
- 선택지 = 쓴다 / 쓰지 않음
- 결정 = 쓰지 않음
- 근거 = 분모·선발 규모에 따라 순위가 바뀜. 수험생에게 단정으로 읽힘
