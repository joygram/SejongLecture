# 사람의 판정 — 국가기술자격 기사 · 정보기술분야

- 결정 칸에 선택지 하나를 그대로 적고, 근거를 한 줄로 적는다
- 아래는 강사 예시. 학생은 자기 판단으로 바꿔 적고 다시 build

## 분모
- 선택지 = 응시 / 접수
- 결정 = 응시
- 근거 = 필기 결시율 26.8–41.1%. 시험을 치르지 않은 사람을 불합격으로 세지 않음

## 집계 단위
- 선택지 = 종목 행만 / 분야 행만
- 결정 = 종목 행만
- 근거 = 분야 행은 종목의 합. 종목 간 차이를 보려는 글

## 포함 종목
- 선택지 = 전부 / 일부
- 결정 = 전부
- 근거 = 네 종목 모두 정보기술 직무로 묶이는 것이 공식 분류

## 작은 표본
- 선택지 = 포함·인원 표시 / 제외 / 비율 쓰지 않음
- 결정 = 포함·인원 표시
- 근거 = 전자계산기조직응용 363명. 빼면 종목 하나가 사라짐, 인원을 함께 보임

## 성별
- 선택지 = 본문 / 부록 / 쓰지 않음
- 결정 = 부록
- 근거 = 원인을 설명할 정보가 없음. 차이를 능력으로 읽히게 본문에 두지 않음

## 가장 어려운 시험
- 선택지 = 필기 기준으로 씀 / 실기 기준으로 씀 / 쓰지 않음
- 결정 = 쓰지 않음
- 근거 = 필기 최저 정보보안, 실기 최저 정보처리. 기준에 따라 답이 바뀜
