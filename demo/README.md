# 같은 팀 리포트 · 강사 시연

## 준비
- 원자료 = `cases/d-grade7/data.csv`, 직군 계의 분야·응시 인원만 사용.
- `python demo/report_workflow.py` → 격리 폴더의 report.html·report.qmd·team-chat.txt 생성.
- 학생 카드 = `../handout/prompts.html`, 입력 원문 = `../handout/practice.md`.

## 흐름
- 30–38′ = 카드 1, 팀 메모 → 첫 문단 → 살릴 문장·바꿀 문장 선택.
- 38–42′ = 카드 2, 같은 자료의 세 인원 → 세 문장 → 숫자 대조.
- 42–46′ = 카드 3, 뜻을 살리는 퇴고.
- 46–54′ = 코딩 에이전트 원샷 시연(자료 수집 → 시트·차트 → 보고서) → 작업 환경 소개.
- 50–52′ = 완성 리포트가 처음 질문에 답하는지 확인. 52–54′ = 팀 채팅 요약.
- 54–60′ = Q&A + 카드 3종, 통계·제품 메뉴 설명으로 확장하지 않음.

## 강조
- 표 = 글에 담을 정보 선택, 그림 = 그 정보를 제대로 전달하는지 확인.
- 문단 = 무엇을 말할지 선택, 채팅 = 팀원이 다음에 할 일 제시.
- 표·그림·문장의 숫자는 같은 자료에서 확인, 경쟁률·응시율 설명 없음.
- 실제 메신저 전송 없음, 채팅 초안만 생성.

## 심화 보관
- 기존 pipeline.py·cases.json·rehearse.py와 자격통계 사례는 보존.
- 경쟁률·분모·구분모집 판정은 기본 강의에서 다루지 않음.
- 도구별 설정 = `../handout/tool-workflows.md`, 내 스타일 입력 = `REPORT_STYLE_TEMPLATE.txt`.

## 배포 전
- 로컬 학생 카드는 갱신됨, 외부 QR 공유 페이지의 내용 반영은 별도 확인 필요.
- 실시간 모델 답은 고정되지 않음, 예문 재현보다 글쓴이의 선택을 확인.

## 코딩 에이전트 원샷 시연
- 입력 = ONESHOT_PROMPT.txt 전체를 프로젝트 루트 에이전트 채팅에 한 번 전달.
- 한마디 입력 = "미리 세팅한 대로 이행해줘" (루트 AGENTS.md·CLAUDE.md가 ONESHOT_PROMPT.txt로 연결).
- 범위 = 새 하위 폴더 → 원자료 확보 → 추출 → 엑셀 시트·차트 → 보고서·공유 초안.
- 보관본 사용 여부·AI 점검·사람 확인 상태 구분.
- 실행 리허설·소요 시간 = 미검증, 기존 한 줄 변경 시연은 사용하지 않음.
