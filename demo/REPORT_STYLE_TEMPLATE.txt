# 내 보고·연구 스타일 입력 양식

## 작성 조건
- 독자 = [수업 담당자 / 동료 / 일반 독자]
- 용도 = [수업 리포트 / 연구 노트 / 발표]
- 질문 = [무엇을 누구와 비교할 것인가]
- 분량 = [문장 수 또는 페이지 수]

## 문서 스타일
- 목차 = [요약→결과→근거 / 질문→방법→결과→한계]
- 문체 = [담백한 문어체 / 내 초안의 어투 유지]
- 표·차트 = [비교 대상·단위·축·색상]
- 수정 방식 = [지적만 / 변경 이유와 원문 대조 / 선택한 부분만]

## 분석 기준
- 자료·기준일·출처 = [직접 확인한 원자료]
- 지표·계산식 = [분자 ÷ 분모]
- 포함·제외 범위 = [집계 단위·빈칸·작은 수 처리]
- 주장 경계 = 관찰·해석 구분, 인과 추측·출처 생성 금지.

## 재편집 환경
- 원자료·계산 코드·문서 원본·스타일 기준 별도 보관.
- 원본 덮어쓰기 대신 사본에서 제안·수정.
- 사용자 선택 전 목차·문체 안 제시 후 대기.
- 기준·자료 수정 뒤 계산·표·그림·본문 갱신, 수치·출처 최종 대조.
