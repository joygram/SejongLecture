## 우리의 질문
우리는 7급 공채 현황으로 짧은 팀 리포트를 만들려고 해.
질문은 “어느 분야에 실제 시험을 본 사람이 많았고, 이것을 인기라고 설명해도 되는가?”야.
우리 팀의 AI 도우미 ‘세롱이’로서, 통계를 처음 보는 사람도 이해할 수 있게 아래 순서로 진행해줘.

## 1. 자료를 찾고 출처를 남겨줘
2026년 국가공무원 7급 공채 1차 필기시험 응시현황을 공식 출처에서 찾아 원본을 보관해줘.
출발점: https://www.data.go.kr/data/15060880/fileData.do
자료의 연도·제목·기관·주소·조회일을 확인해줘. 웹에서 확보하지 못하면 프로젝트의 보관본을 확인하고, 보관본 사용 사실을 밝혀줘.
해당 연도의 자료를 확보하지 못하면 숫자를 만들거나 다른 연도로 대신하지 말고, 못 구한 항목을 알려줘.

## 2. 원본을 편집 가능한 표로 정리해줘
엑셀에서 출처 → 추출한 원문 → 정리한 데이터 → 비교표를 따라가며 숫자를 확인할 수 있게 해줘.
원본의 페이지·표기와 정리한 값·단위를 남기고, 빈칸을 임의로 채우지 마.
비교에는 직군별 합계와 실제 시험 본 사람 수를 쓰고, 총계와 세부 항목을 중복해서 더하지 마.

## 3. 같은 숫자를 두 가지로 표현해줘
편집 가능한 가로 막대차트 A·B를 만들어줘. A는 인원이 가장 많은 분야, B는 상대적으로 적은 분야를 강조해줘.
두 차트의 숫자·축 범위·정렬·단위는 같게 두고 제목과 강조만 바꿔줘.
표와 두 차트를 나란히 비교하며, 각 표현에서 무엇이 먼저 보이는지 설명해줘.
표와 그림은 번호로 부르고 무엇을 볼지 밝혀줘. 강조 선택도 해석이라는 점을 근거 문헌과 함께 짚어줘.

## 4. 질문에 답하는 짧은 보고서를 써줘
질문 → 표와 두 표현 비교 → 자료로 알 수 있는 사실 → 인기라고 말할 수 있을까요 → 아직 알 수 없는 이유 순서로 써줘.
‘인기’는 기준을 먼저 정해야 하는 말이라고 설명하고, 응시인원과 선발 1명당 응시인원의 순위를 실제 숫자로 비교해줘.
경쟁률 보도자료와 지원 동기 연구를 찾아 근거로 붙이고, 접수와 실제 응시를 구분해줘. 논문은 초록만 읽었는지 본문도 읽었는지 밝혀줘.
결론은 ‘기준 + 숫자 + 한계’로 써줘. 이 자료로 어디서 시험을 본 사람이 많았는지는 알 수 있지만, 왜 골랐는지·선호하는지는 단정하지 마.

## 5. 점검한 일과 사람이 확인할 일을 보여줘
원본·표·차트·본문의 숫자를 대조하고, 실제로 점검한 결과와 미확인 항목을 남겨줘.
보고서에 ‘단계 / 세롱이 / 사람’ 확인표를 넣어 AI가 도운 일, 우리 팀이 직접 확인한 일, 결정할 일을 구분해줘. 사람 미확인은 그대로 남겨줘.
하단에는 출처표와 윤리적 사용 가이드를 넣고, 사람이 제공한 자료와 세롱이가 찾은 자료를 구분해줘.

## 6. 초안 다음에 우리가 할 일을 연결해줘
확인 → 판단 → 우리 글로 수정 → 다시 만들고 재대조 → 사람 승인·직접 공유 순서의 체크리스트를 보고서에 넣어줘.
확인: 원본 숫자·엑셀 차트 화면·출처·이용 조건과 이번에 남은 미확인 항목을 살펴봐요.
판단: ‘인기’라는 말을 쓸지, 어떤 기준과 차트 표현을 택할지 결정해요.
수정: 우리 관심을 담은 첫 문장으로 고치고, 고친 문장과 이유를 기록해요.
재대조: 세롱이에게 수정을 요청하고, 결과를 다시 만들어 원본과 맞춰봐요.
공유: 팀 채팅 초안을 고치고 사람 확인자·날짜·실제 공유 주소를 넣은 뒤, 사람이 승인하고 직접 보내요.
각 할 일에는 실제로 열어볼 파일·출처·보고서 부분의 링크를 붙여줘.

## 시간과 완성할 결과
이 요청을 받은 때부터 5분 안에 생성·점검·결과 안내까지 마쳐줘. 시간을 기록하고, 끝내지 못한 일은 완료했다고 쓰지 마.
새 결과 폴더에 원본 자료, 편집 가능한 엑셀, 보고서 원고와 열어볼 보고서, 출처·점검 기록, 후속 체크리스트를 남겨줘.
다시 실행할 코드와 안내, 4줄 이내의 팀 채팅 초안도 함께 만들어줘. 보고서와 채팅은 요체로 써줘.
계획만 제시하지 말고 끝까지 실행하되, 기존 파일을 수정하거나 실제 전송하지 마.
진행 중에는 각 단계에서 무엇을 했고 무엇을 확인했는지 짧게 알려줘. 제작·검증의 구현 세부사항은 프로젝트의 에이전트 규칙을 따라줘.
