# 청중 화면 편집 기준

## 인물·독자
- 보고서 독자 = 공무원 시험 현황이 궁금한 일반 독자
- 팀원 = 공동 작성자·검토자; 팀 채팅은 진행 상황·검토할 일 공유
- 프레젠테이션·학생 카드 = AI로 통일; 세롱이 이름·로고·제작 표기는 원샷 결과물에서만 사용
- 채팅 얼굴 = 지민·수아·나 각각 고정; 도입·마지막 채팅에서 같은 얼굴 유지

## 이야기·요청
- 출발 = 올해 어느 분야가 인기 있는가, 행정직에 사람이 많다던데, 이걸로 보고서를 쓰고 싶다
- 전개 = 메모로 서론 → 표·차트·문장 → 인원이 많다는 사실과 인기 해석의 차이 발견 → 수정·공유
- 요청 = 역할·상황·제공 재료·작업을 명시하는 지침; 서론에서 데이터 사용을 일괄 금지하지 않음; 사용한 사실·수치의 출처 확인
- 제외 = [자료 확인 후] 같은 임시 표시·요체 지정·출발 메모에 학습 결론 주입

## 표현·이미지
- 차트 = A/B 고르기 질문 대신 보고서에서 포커스하려는 모습과 강조·모양의 관계 설명
- 삽화 = AI와 글쓰기 과정의 개념 비유; 실제 통계 표·차트를 대신하지 않음
- 사람 역할 = 작업의 길잡이와 판단; AI 제안·실행과 구분
- 운영 = 시간표·강사 시연 시나리오는 발표자 노트; 청중 화면은 작업 방식 지시와 결과 검토

## QR·검증
- QR = 카드 설명이 모두 끝난 뒤 별도 직접 해보기 화면에 1개; 카드·시연·나머지 장에 반복 금지
- 검증 = python slides/workbench.py build → check → pdf; 내용 정본·학생 카드 정본에서 생성
- 사람 확인 필요 = 프로젝터 가독성·QR 실기기 스캔·외부 배포 페이지 반영·최종 내용 승인
