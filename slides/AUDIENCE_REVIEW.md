# 청중·스토리 점검

## 기준
- 합의된 60분 시간표·세 학습 목표 유지.
- 같은 가상 팀 과제 → 같은 리포트 → 같은 팀 채팅방 공유.
- 원자료 = 기존 7급 공채, 새 가상 설문·별도 주제 추가 없음.
- 본문 = 분야·시험 본 인원만, 통계 계산·경쟁률·응시율·분모 설명 제외.

## 장면별 목적
| 화면 | 보여주는 이유 | 사람이 생각할 것 |
| --- | --- | --- |
| 팀 메모 | 글의 질문·독자 설정 | 무엇을 말하려는가 |
| 표 | 글에 담을 정보 선택 | 어떤 정보가 필요한가 |
| 그림 | 같은 정보인지 대조 | 그림이 자료를 바꾸었는가 |
| 퇴고 | 뜻·강조점·문체 선택 | 왜 이 문장을 쓰는가 |
| 완성본 | 처음 질문과 결과 연결 | 글이 질문에 답하는가 |
| 팀 채팅 | 협업의 다음 행동 | 팀원에게 무엇을 부탁할까 |

## 예시 구분
- 팀 대화·작성 문단·오류 차트 = 수업용 작성 예시.
- 차트 비교 = 동일 수치·축·순서, 제목과 강조 차이에 따른 관점 비교.
- 실제 인원 = 원자료에서 세 분야를 그대로 읽어 사용, 표·그림·문장 대조.
- 법원 사례 = 출처·후속 허위 대응에 관한 실제 사례, AI 사용 자체가 제재 사유라는 설명 금지.

## 확인 범위
- 자동 검사 결과 = 워크벤치의 최신 check-data.js.
- 실제 프로젝터 가독성·QR 실기기 스캔·외부 공유 페이지 반영 = 미검증.
- 실시간 AI 출력·청중 반응 = 미검증.
